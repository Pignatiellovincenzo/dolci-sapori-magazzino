# Gestionale Magazzino — Dolci Sapori

Applicazione web per la gestione dei due magazzini aziendali (materie prime e prodotti finiti surgelati), con tracciamento a lotti e collegamento ai flussi di produzione e vendita.

## Stack

- **Database**: [Supabase](https://supabase.com) (Postgres)
- **Frontend**: HTML/CSS/JS, responsive (PC e cellulare)
- **Hosting**: GitHub Pages
